PING PONG MASTERS OF BALL - ALFA VERSION

A ping pong game featuring legendary battles, power-ups, meteorites, and lightning bolts.

What it’s about:
You are "?", a 15-year-old teenager who wants to become a professional table tennis player.

How to play:


W/S = move racket,  
A/D = spin the racket, 
E = shoot, 
P = pause, 
R = restart  
Touch buttons appear on the mobile phone


Modes:
STORY MODE,
VS CPU, 
Local - 2 players on the same PC,  
Online - 2 devices with a room code


Powerups:
Fireball, 
Gun, 
Remote-controlled, 
And more...
